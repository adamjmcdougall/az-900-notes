# What is cloud computing?
  Compute power, storage and networking owned and operated by a cloud provider and rented out to end users on an as-needed basis (on-demand provisioning)
  
  This exchanges up front costs for ongoing costs (CAPEX vs OPEX) when compared against traditional on-premises hardware/software purchases
  
  It provides global reach and expansibility, much quicker and easier than traditional hardware purchases

## When using a cloud provider, you're always responsible for;
  Your data stored in cloud services
  
  Devices and users that are allowed to access your cloud environment
  
  The accounts and identities of people, services and devices within the environment.

## When using a cloud provider, they are always responsible for;
  The physical datacenter (the land, the building, access controls)

  The physical network (cabling)

  The physical hosts (server hosts)

  Infrastructure (power, water, temperature controls)

## The selected service model will determine who manages things like;
  Operating systems and hypervisors

  Network controls

  Applications

  Identity and access
